# Router research

- [Horizontal Gene Transfer](HORIZONTAL-GENE-TRANSFER.md): CLI MVP requirements.
- [Backwards Induction](BACKWARDS-INDUCTION.md): goals, anti-goals, reservations,
  insistences, and research stance, including the ensemble vision.

The router is not implemented. The
[Apple Vision translation experiment](../../Experiments/AppleVisionTranslation/README.md)
is a useful channel example. Its package, preparation, and API do not define the
router's structure. [Portability](../Portability/README.md) is a parallel track
that supplies evidence for decisions about framework delegation and future APIs.
