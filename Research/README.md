# hazy research

Two parallel tracks share experimental evidence:

- [Router](Router/README.md): how to allocate comparison effort and present
  provisional relationships within an image batch.
- [Portability](Portability/README.md): how to understand framework handoffs and
  decide which capabilities can preserve the same caller API on another platform.

[Experiments](../Experiments/README.md) contains runnable, explicitly scoped
implementations. An experiment can inform either track without prescribing the
router architecture. No router or Linux implementation exists yet.
