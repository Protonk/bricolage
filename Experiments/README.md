# Channel experiments

Each experiment owns its package, tests, tools, and implementation documentation.
The directory contains working evidence for the research tracks, not router code.

[AppleVisionTranslation](AppleVisionTranslation/README.md) is the current macOS
experiment. Its executable is `hazy-vision-translation`, and its Swift library is
`AppleVisionTranslationExperiment`. Run Swift commands with that package path.
