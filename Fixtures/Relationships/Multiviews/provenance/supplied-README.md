# hazy multiview fixture v1 — Motorcycle

**Exactly two independently captured photographs of the same physical scene.**

Import only the `images/` directory into hazy. The images are the left and right physical views of a motorcycle in a garage from the **Middlebury 2014 stereo dataset**. The files have opaque names, and no duplicate or synthetic-image variant is added.

**Important preprocessing qualification:** These are not raw camera files. Middlebury's captured stereo pair was geometrically rectified; scikit-image further downsampled each source image by a factor of four. Neither file was generated by transforming the other, however. They come from two distinct physical camera viewpoints. They are thus distinct captures of one scene, but a *relatively easy* multiview task: the two cameras have a small baseline and almost identical framing.

The two images are RGB PNGs at 741 × 500 pixels, copied byte-for-byte from scikit-image 0.26.0's distributed `motorcycle_left.png` and `motorcycle_right.png` sample files. (You can compare `SHA256SUMS.txt`.) The original dataset was collected by Nera Nesic, Porter Westling, Xi Wang, York Kitajima, Greg Krathwohl, and Daniel Scharstein at Middlebury College, with further calibration refinements described in the project's site.

**Label:** both entries have `scene_id=middlebury2014-motorcycle` in `manifest.csv`. This means *same photographed scene*, not a prescribed similarity score or necessarily a requirement that hazy cluster them at any selected threshold. With only one positive pair there are no negative cases in this archive.

## Contents

- `images/`: exactly 2 independently taken source views, with opaque names
- `manifest.csv` and `manifest.json`: scene grouping, physical view, processing history and checksums
- `SHA256SUMS.txt`: raw file hashes; run `shasum -a 256 -c SHA256SUMS.txt` from this directory
