# Puddle Inversions — 45 file-page candidates

These are **leads**, not acquired images or an accepted heap. Exact Commons file titles and URLs are retained. `Page checked` means the text of the individual file description and licensing sections was reviewed; **no image pixels or thumbnails were visually reviewed** in this handoff. `Listing only` means only the category listing was consulted, and no creator or license was inferred. Width and height were transcribed from the category listing.

Source: [Wikimedia Commons — Category:Reflections in puddles](https://commons.wikimedia.org/wiki/Category:Reflections_in_puddles), accessed 2026-11-02 via a cached page that displayed 200 direct files of 432. Subcategories excluded. Selection is purposefully not a rigorous quality or similarity filter.
