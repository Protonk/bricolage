# Hazy `prompt_heap` — repeatable sourcing and acquisition contract

Applicable to PS01 and future loose-image heap elements. These instructions incorporate the SF01 local-agent feedback. **Do not create a new fixture kind** or introduce semantic ground-truth clusters.

1. **Intent first.** Include the heap identity, short visual prompt, exclusions, acceptable looseness and approximate target count. Count is a target, not a minimum. State a shortfall without padding with weak or related images.
2. **Actual thumbnail inspection, early.** Category matches, text descriptions and search snippets are only leads. If preview bytes exist, inspect their *composition*, not just their subject. Mark `accept`, `reject`, or `defer` with a short visual reason. Unviewed leads stay `pending_visual_review`; never assign a fabricated numerical similarity threshold or a core/border/outlier label.
3. **Independent axes.** `screening_status` and `visually_accepted` record judgments. Preview and source-acquisition statuses separately record transport. 59 accepts with 48 downloads means **59 accepts**, not 48. No acquisition error may change a visual decision.
4. **Identities.** Preserve stable candidate IDs, exact Commons `File:` titles, file-page URLs, discovery URLs, and all preexisting `candidates.jsonl` fields. JSONL is canonical; derive CSV from the union of keys in all JSONL records, including API-enriched fields added in later runs.
5. **Evidence layout.** Put *all* acquired preview bytes, contact sheets, and incomplete **media** bodies in `previews/`. Put successfully acquired reduced source bytes in `sources/`. Put API metadata replies, transport logs and JSON partials, resolved rendition URLs, decoded dimensions, byte hashes, credits, licenses, provenance doubts, and review logs in `provenance/` and JSONL. Unknown values remain `null`.
6. **Provenance.** Exclude obvious duplicates, crops, sequences, and related captures. Use upstream IDs, URLs, exact hashes, and other evidence. Check prior heap additions whenever their actual inventories are supplied; a different title, author, or date is not evidence of independence. Record uncertainty. Search buckets are not fixture families or expected clusters.
7. **Conservative Wikimedia access.** Start with one small preview. Pace requests serially; cache both API replies and acquired media. Use ONLY MediaWiki API-returned rendition URLs. Stop, retaining diagnostics, on access/rate-limit errors (including 403/429/503/529) or transport errors. An HTTP 200 followed by a timed-out body is **a failed transfer with HTTP status 200**, not a completed acquisition. Retain any media partial under `previews/partials/`, log actual status, headers, bytes received, and exception. No automatic retry or identity rotation. Require explicit acknowledgement of prior error before next attempt.
8. **Reported versus decoded dimensions.** Nominal ~320px previews and ~1600px source requests are not guarantees. Record exact API-returned URL, declared dimensions, actual decoded dimensions, actual byte count, SHA-256, and `api_returned_rendition` versus `api_reported_unscaled_original` without recropping, re-encoding, or upscaling.
9. **Handoff.** Deliver data, original acquired bytes, provenance and a short README. The local integrator assigns opaque comparison input filenames, final manifests, batches, and checksums, preserving `prompt_heap` and the original image framing.

## PS01 specifics

- **Element label:** `pale-skies-dark-lower-halves` (`PS01`).
- **Visual prompt:** Photographs with a comparatively pale, broadly continuous sky occupying a substantial upper region and a darker, more detailed or silhouetted lower region; the transition can be a horizon, treeline, roofline, ridge, shoreline, or layered haze.
- **Exclude:** Synthetic imagery, obvious variants, alternate captures, dominant close-up subjects, overly dramatic saturated sunsets, and images that are only *about* fog/clouds but lack the visual upper/lower split.
- **Looseness:** Horizon height, boundary sharpness, fog density, foreground texture and subject matter may vary. A slightly blue or pink-gray sky is fine. Some unbalanced or unusual compositions are welcome when the broad visual relationship persists.
- **Target:** Roughly 65 accepted, with 50–80 a useful planning band, subject to actual thumbnail inspection and independent provenance.
